# Мультик под голос

Плагин для Claude Code. Вы даёте озвучку или тему, Claude делает вертикальный мультик 1080×1920 с человечками: чистит голос,
рисует сцены кодом, ставит пословные субтитры, музыку и эффекты. Платные сервисы и генераторы картинок не нужны.

## Установка

**Проще всего.** Отправьте этот архив в Claude Code и напишите: «Установи этот плагин».

**Инструкция для Claude.** Распакуй архив так, чтобы получилась папка `~/.claude/skills/montazh-multik/`, внутри которой сразу
лежат `.claude-plugin/plugin.json`, `skills/` и этот `README.md` (без лишней вложенной папки). Затем запусти
`python ~/.claude/skills/montazh-multik/skills/montazh-multik/scripts/new_project.py --check` (или `python3`) и покажи, чего
не хватает. Недостающие программы ставь только после согласия пользователя. В конце скажи пользователю начать новую сессию
Claude Code, чтобы плагин подхватился.

**Вручную, из GitHub-репозитория:**

```bash
claude plugin marketplace add ВЛАДЕЛЕЦ/РЕПОЗИТОРИЙ
```

```bash
claude plugin install montazh-multik@montazh-multik-market
```

## Как пользоваться

Напишите в новой сессии, например:

- «Сделай мультик из этой озвучки: C:\путь\голос.mp3»
- «Сделай мультик про то, почему в самолётах иллюминаторы круглые»

Если озвучки нет, Claude напишет сценарий и попросит её записать.

## Что понадобится

- Node.js 18+, ffmpeg (полная сборка), Python 3.9+ с пакетами `numpy` и `faster-whisper`. Проверку делает сам плагин.
- Около 1 ГБ места и интернет при первом запуске: зависимости Remotion, браузер для рендера и модель распознавания речи.
  Потом всё работает с готовыми файлами, сама расшифровка идёт на вашем компьютере.

## Лицензии

- Рисовка работает на [Remotion](https://www.remotion.dev). Для частных лиц и небольших компаний он бесплатен, более крупным
  компаниям нужна его коммерческая лицензия: условия на [remotion.dev/license](https://remotion.dev/license).
- Шрифт Montserrat распространяется по SIL Open Font License: `skills/montazh-multik/fonts/OFL.txt`.
- Звуки и музыка в `assets/` синтезированы скриптом `scripts/make_audio.py`, чужих записей в плагине нет.
