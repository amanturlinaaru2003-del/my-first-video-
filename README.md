# my-first-video

HyperFrames + GSAP video projects.

- `test-animation/` — 6-second test title card (`index.html`), rendered to `test-animation/renders/test-animation.mp4`.
- `.claude/skills/` → `.agents/skills/` — official HyperFrames (heygen-com/hyperframes) and GSAP (greensock/gsap-skills) skills for Claude Code. Versions pinned in `skills-lock.json`.

## Render

```bash
cd test-animation
npx hyperframes check                                   # validate
npx hyperframes snapshot --at 1,3,5                     # preview still frames
npx hyperframes render -o renders/test-animation.mp4    # export MP4
```

Requires Node.js >= 22, FFmpeg and Chrome/Chromium (`npx hyperframes doctor` checks all three).

## sleep-film — «НЕГЕ ҰЙЫҚТАЙ АЛМАЙСЫҢ?» (50 s, 9:16 Reels)

- Render: `sleep-film/renders/nege-uiyktai-almaisyn.mp4` (1080×1920, 30 fps, H.264 + AAC).
- Re-render: `cd sleep-film && node tools/build.mjs && npx hyperframes check && npx hyperframes render -o renders/out.mp4`
- Scenes are generated by `tools/build.mjs` + `tools/lib.mjs` (one shared character rig and bedroom set).
- Voice: Piper TTS, Kazakh `kk_KZ-issai-high`, male speaker 1 (ISSAI KazakhTTS, CC BY 4.0), made locally by `tools/build_voice.py`.
- Music: generated locally with MusicGen-small (Meta, via `Xenova/musicgen-small`; model weights CC BY-NC 4.0, so non-commercial use) by `tools/musicgen.mjs`.
  The requested Pixabay track could not be downloaded automatically; replace `assets/audio/music.wav` with it to swap.
- Sound effects: bundled with HyperFrames. Font: Montserrat (SIL OFL). GSAP 3.15 is vendored in `lib/`.

## escalator-film — «ЖОҒАРЫ» (29 s, 9:16)

Original short in a minimalist night-mall style: МОТИВАЦИЯ, ЭГО, ҚОРҚЫНЫШ and ТӘРТІП ride an escalator up; the power cuts out, the escalator stops, and only ТӘРТІП keeps walking to the top. Closing line: «Мотивация тоқтап қалады. Тәртіп — жүре береді.»

- Render: `escalator-film/renders/zhogary.mp4` (1080×1920, 30 fps, H.264 + AAC).
- Re-render: `cd escalator-film && node tools/build.mjs && npx hyperframes check && npx hyperframes render -o renders/out.mp4`
- All drawing is in `lib/mall.js` (canvas, one shared character rig and mall set); scene timing and camera moves are in `tools/build.mjs`. Character labels: `LABELS` at the top of `lib/mall.js`.
- Music: generated locally with MusicGen-small (Meta, `Xenova/musicgen-small`; weights CC BY-NC 4.0, so non-commercial use). Replace `assets/audio/music.wav` to swap it. Sound effects are bundled with HyperFrames.

## energy-film — «ЭНЕРГЕТИК» (29 s, 9:16)

Same night-mall style. «ЭНЕРГЕТИК ІШЕДІ» drinks a can, his battery jumps to 100 %, he sprints up the stairs, crashes halfway (battery 6 %, 150+ BPM), tries a second can and crashes again. «ЭНЕРГЕТИК ІШПЕЙДІ» drinks water and walks at an even pace (70 %, 72 BPM), passes him and reaches the top. Closing: «Энергетик — қарызға алынған қуат. Нағыз қуат — ұйқы, су, қозғалыс.»

- Render: `energy-film/renders/energetik.mp4`. Re-render: `cd energy-film && node tools/build.mjs && npx hyperframes render -o renders/out.mp4`
- Drawing: `lib/mall.js` (adds the cans, water bottle, battery/heart-rate HUD and speed lines); scenes: `tools/build.mjs`.
- Music: MusicGen-small, generated locally (CC BY-NC 4.0 weights, non-commercial). Swap `assets/audio/music.wav` to change it.

## coma-film — «10 БАНКА» (50 s, 9:16)

One day, ten energy drinks: 07:00 bedroom → 08:10 road → 10:30 class → 12:00 work → 13:30 lunch → 21:00 gaming → 03:00 night (HUD counts cans 1/10…10/10 and heart rate up to 175 BPM). He stands, gets dizzy, collapses. POV in the ambulance (eyelids opening and closing, medics, slow ECG), CPR wide shot, coma prayer («Осыдан тірі шықсам, енді ешқашан энергетик ішпеймін»), wakes in hospital and raises his hands — «Тәубе. Денсаулық — бір-ақ рет беріледі.»

- Render: `coma-film/renders/10-banka.mp4`. Re-render: `cd coma-film && node tools/build.mjs && npx hyperframes render -o renders/out.mp4`
- Drawing (sets, rig, HUD, ECG, eyelids): `lib/life.js`; scene timing, text and sound placement: `tools/build.mjs`.
- Music: two MusicGen-small tracks generated locally (CC BY-NC 4.0 weights, non-commercial). Heartbeats are built from the bundled HyperFrames bass hit; other effects are the bundled HyperFrames library (`assets/audio/CREDITS.md`).
